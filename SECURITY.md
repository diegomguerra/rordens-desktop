# Segurança

Encontrou uma falha? Escreva para **contact@rordens.ai** com o assunto "Segurança". Respondemos em até 5 dias úteis. Não divulgue publicamente antes de falarmos.

O app é uma janela que abre `https://rordens.ai/people`. As falhas do serviço em si (conta, conversas, cobrança) também valem para este contato.
